**Paths:**
- Test names: Django tests are given as `tests.<app>.<module>.<Class>.<test>`. Playwright tests are given as `<spec file> › <title>`.
- Code paths are relative to the project root.
- **Evidence** files are in `docs/evidence/`. That folder is submitted separately and is not in the Git repository, so those links only work in the full submission.

**Dummy APIs.** OrgaTEX, Scale, Scanner and Printer are **Dummy APIs**. They are training contracts defined by this project, not the real interfaces.
